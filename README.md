# Paintball gun model slot

Put your exported gun model here with this exact filename:

```text
models/paintball_gun/paintball_gun.glb
```

Use a `.glb` export with the barrel pointing along the model's local **-Z** axis and the top of the gun along **+Y**. The game automatically scales and centers the model, then shows it in first person instead of the built-in placeholder marker. Keep the GLB self-contained (embed its textures during export).

If the file is absent or fails to load, the built-in marker remains visible. Reload the game after adding or replacing the GLB.
